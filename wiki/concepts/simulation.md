# Simulation (시뮬레이션)

## 정의
실제 환경을 가상 세계에 재현하여 AI 모델을 학습시키거나 테스트하는 기술.

## 필요성
- **비용 절감**: 실제 로봇 파손 위험 없이 무한 반복 실험 가능.
- **안전 확보**: 위험한 상황(낙상, 충돌 등)을 안전하게 재현.
- **데이터 확보**: 희귀하거나 극단적인 상황(Edge Cases)의 데이터 생성 용이.

## 기술적 과제
- **Sim-to-Real Gap**: 가상 환경과 실제 환경의 물리적 차이를 극복하는 것이 핵심 과제.
